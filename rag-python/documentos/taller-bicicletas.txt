MANUAL DEL TALLER COMUNITARIO PEDAL
Estas normas son ficticias y se utilizan como material de aprendizaje.

HORARIO Y RESERVAS
El taller abre los martes y jueves de 17:00 a 20:00 y los sábados de 10:00 a 13:00. Para reservar un puesto de reparación hay que indicar el nombre y el tipo de avería. Cada reserva permite utilizar un puesto durante una hora. Si se necesita más tiempo, debe solicitarse otra franja disponible.

HERRAMIENTAS
Las herramientas compartidas se utilizan dentro del taller y se devuelven al panel al terminar. No se permite llevarlas a casa. Si una herramienta está dañada, se avisa a la persona responsable antes de usarla. El taller dispone de llaves, desmontables, bombas de aire y soportes para bicicletas.

MATERIALES Y RECAMBIOS
El taller presta las herramientas sin coste. Cada participante debe traer los recambios que necesite, como cámaras, cables o pastillas de freno. Hay parches y lubricante para pequeñas reparaciones. El manual no establece precios de recambios ni tarifas por otros servicios.

CURSO DE PINCHAZOS
El primer sábado de cada mes se organiza un curso para reparar pinchazos. La inscripción se cierra el jueves anterior a las 18:00. Cada sesión admite ocho personas. No hace falta experiencia, pero cada participante debe traer su bicicleta. El curso dura noventa minutos.

CANCELACIONES
Si no puedes acudir a una reserva, debes cancelarla al menos doce horas antes del inicio. Puedes hacerlo por el mismo canal utilizado para reservar. Así otra persona podrá utilizar el puesto. El manual no especifica sanciones por una cancelación tardía.
